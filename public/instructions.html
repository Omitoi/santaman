Instructions

Hosting a Game

  1. Navigate to the Host Game page from the main menu.
  2. Enter your desired player name.
  3. Click the Host Game button.
  4. You will be redirected to the game lobby.
  5. Share the Room ID shown on the screen with your friends so they can join.

Joining a Game

  1. Navigate to the Join Game page from the main menu.
  2. Enter your player name.
  3. Enter the Room ID you received from the host.
  4. Click the Join Game button.
  5. You will be taken to the game lobby to wait for the host to start the game.

Game objective

Place bombs, destroy walls, pick up powerups, and destroy the other players to win. Try not to get blown up by the other players.
